What changed from the old v1.3b / Happy Hare v3 preset

  • Tool change is now just T[next_extruder]. _SET_LOC_AFTER_TOOLCHANGE no longer exists and T0..T11 take no parameters.
  • Start G-code adds SOAK=0 (else an 8 min bed soak), TOTAL_LAYER, and a fixed CHAMBER=0.
  • Firmware retraction is on (Klippain sets the length per material). Slicer retraction values below only apply if you turn it off.
  • Accel limits dropped from 15000+ to X 7000 / Y 3500 to match the input shapers.
  • Prime tower off for the no-purge test; ramming, cooling moves and slicer-side filament-change retraction off (Happy Hare does the tip form).
